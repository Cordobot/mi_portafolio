# Adrián Alvarez | Android Developer Portfolio 🚀

Este es mi portafolio profesional, diseñado para ofrecer una experiencia premium y moderna, destacando mis habilidades y proyectos en el ecosistema Android.

## 🌟 Características

- **Diseño Premium**: Estética moderna con glassmorphism, modo oscuro nativo y animaciones fluidas.
- **Multilingüe**: Soporte completo para Español e Inglés con cambio dinámico.
- **Sin framework**: HTML5, Tailwind CSS (compilado con `npm run build`) y JavaScript sin dependencias pesadas.
- **Responsive**: Totalmente optimizado para dispositivos móviles, tablets y escritorio.
- **Interactividad**: Efecto de máquina de escribir, modales de contacto y sistema de navegación suave.
- **Apps en vivo**: cada proyecto se muestra dentro de un teléfono (o una TV) con un video real de la app, filtros por tecnología, APK instalable con QR y página de caso de estudio.
- **Detalles de Android**: barra de estado, barra de navegación inferior, FAB extendido, efecto ripple, *snackbars*, hoja inferior y selector de color al estilo Material You.

## 🛠️ Stack Tecnológico

- **Core**: HTML5, CSS3, JavaScript (ES6+).
- **Styling**: Tailwind CSS, Custom Keyframe Animations.
- **Icons**: Lucide Icons.
- **Assets**: Imágenes optimizadas y SVGs.

## 📂 Estructura del Proyecto

- `index.html`: Estructura semántica y contenedores principales.
- `style.css`: Definición de animaciones, variables de diseño y clases personalizadas.
- `script.js`: Lógica de internacionalización, gestión de temas (dark/light) e interactividad.
- `projects.js`: Datos de los proyectos (textos ES/EN, etiquetas, casos de estudio y enlaces a los APK).
- `stack.js` y `snippets.js`: Logos del stack y fragmentos de Kotlin de la sección de arquitectura.
- `theme.js`: Paleta Material You, color de la barra del navegador y efecto ripple (compartido).
- `proyecto.html` + `case.js`: Página de caso de estudio (`proyecto.html?p=pokeverse`).
- `assets/`: Recursos visuales; `assets/projects/video/` tiene las grabaciones de cada app y `assets/qr/` los QR de descarga.

## 🚀 Despliegue

Al ser un sitio estático puro, puede ser desplegado instantáneamente en:
- GitHub Pages
- Vercel
- Netlify
- O simplemente abriendo `index.html` en cualquier navegador.
